# Reconciliation contract
Scope is one warehouse and one SKU per row. Each row gives snapshot time, book units, counted units, countedAt, version, and signed movements after snapshot. Rebuild book quantity at count time and apply only the count discrepancy to current stock. Duplicate movement IDs with identical bytes are counted once; conflicts fail. Prepare one atomic adjustment plan. Apply only after explicit approval if the full current batch still matches its SHA-256 fingerprint. All quantities are integer units and all timestamps are UTC ISO seconds. Demo state stays within this browser tab.
